# 离谱聊天室

一个「换个人格再开口」的实时聊天室：你说人话，AI 用当前人设把它改写得离谱，同时暗地里每人还有一个不想被别人发现的秘密任务。

根目录的 `index.html` 是早期单机 Demo；真正的全栈应用位于 `apps/web`（React + Vite）与 `apps/api`（NestJS + Fastify）。

## 技术栈

- **前端**：React + Vite + Socket.IO Client
- **后端**：NestJS + Fastify + Socket.IO Gateway
- **数据库**：MySQL 8.4（业务数据）
- **缓存/状态**：Redis（在线状态、房间序号、幂等、排行榜、失控规则）
- **大模型**：任意 OpenAI-compatible 接口（未配置 Key 时自动进入本地 Mock 模式）
- **部署**：Docker Compose 一键启动

## 一键启动

```bash
cp .env.example .env
docker compose up -d --build
```

打开 <http://localhost:8080>。

默认 `LLM_MOCK_MODE=true`，无需任何密钥即可体验完整流程。要接入真实模型，在 `.env` 中配置：

```text
LLM_BASE_URL=https://你的模型服务/v1
LLM_API_KEY=你的密钥
LLM_MODEL=模型名称
LLM_MOCK_MODE=false
```

修改环境变量后重新执行 `docker compose up -d --build`。

Compose 会启动以下服务：

| 服务 | 地址 | 说明 |
|------|------|------|
| Web | `http://localhost:8080` | 前端界面 |
| API | `http://localhost:3000` | HTTP + WebSocket |
| MySQL | `127.0.0.1:3306` | 数据库（首次启动自动建表） |
| Redis | `127.0.0.1:6379` | 缓存 |

> 仓库里的数据库 / Redis 密码、JWT 密钥都只是本地开发默认值，**生产环境必须替换**（见 `.env.example`）。

## 内置人格

| 人格 | 玩法 |
|------|------|
| 程序员 | 把生活编译成可运行的代码 |
| 英语老师 | 每句话都忍不住划重点 |
| 古风文人 | 凡事先叹一声，再押个韵 |
| 霸道总裁 | 短句、命令，以及不容置疑 |
| 灵魂歌手 | 把每句话都唱成两句歌词 |
| 说反话大师 | 正话反说，永远拧着来 |
| 新闻主播 | 什么都用联播腔播报 |
| 夸夸群主 | 先夸你一句，再认真回答 |
| 热梗大师 | 句句都是网络热梗 |

所有内置人格都可在「人物管理台」里停用、删除，也可以创建你自己的自定义人格（含发言习惯、态度风格、转换规则、代表色和符号）。

## 功能

- **人物系统**：内置人格 + 自定义人格 CRUD，支持版本化（历史消息保留当时的人设快照）。
- **实时聊天**：WebSocket 推送；输入后**立即转换并广播，发送者不能修改**。
- **秘密任务**：进入主题任务局后自动派发，分「对抗 / 合作 / 恶搞」三类，可主动提交，由服务端硬校验 + AI 复核判定。
- **排行榜**：任务得分实时汇总，房间内排名。
- **失控指数**：发言、切人设、完成任务都会累积；满值后触发随机失控规则，可叠加，AI 会自动遵守这些规则。
- **空房自动销毁**：房间空闲超时后自动回收。
- **响应式**：桌面与手机端布局，回车发送、焦点样式。


## 演示建议

1. 在大厅选一个内置人格（例如「灵魂歌手」）。
2. 创建或加入一个「主题任务局」。
3. 输入一句人话，观察它被改写成歌词并立即发出。
4. 完成你的秘密任务，点「我觉得完成了」看 AI 判定。
5. 多发言让「失控指数」拉满，看看叠加的失控规则怎么让全场一起离谱。

## 已知边界

- 未配置大模型 Key 时走 Mock 模式，转换结果是规则生成而非真实模型输出。
- 会话凭证、房间状态等依赖 Redis；首次启动前不要清空 Redis 数据（否则需要重新登录）。
